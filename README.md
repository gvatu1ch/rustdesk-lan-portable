# RustDesk LAN — удалённый рабочий стол (аналог AnyDesk)

Портативная сборка [RustDesk](https://github.com/rustdesk/rustdesk) 1.5.0 для Windows x64 для подключения по локальной сети (LAN).

RustDesk — open-source программа под лицензией **AGPL-3.0**. В папке `LICENSE.rustdesk.txt` — текст лицензии.

## Скачивание

Перейди в раздел **Releases** этого репозитория и скачай
`rustdesk-1.5.0-windows-x86_64-portable.zip`. Распакуй в любую папку —
установка не требуется.

## Как пользоваться (локальная сеть)

### На компьютере, К КОТОРОМУ подключаются

1. Запусти `rustdesk.exe`.
2. Настройки → Сеть → **Прямой доступ по IP** — включи (порт 21118).
3. Оставь подтверждение «вручную»: каждое подключение показывается окном,
   которое нужно принять.

### На компьютере, С КОТОРОГО подключаются

1. Запусти `rustdesk.exe`.
2. В поле ID введи IP-адрес первого компьютера (узнать: `ipconfig`).
3. После подключения на первом ПК появится окно запроса — владелец
   нажимает **«Принять»** и вводит/подтверждает пароль.

## Важно

- Работает только в одной сети (LAN/Wi-Fi). Для подключения через интернет
  нужен свой сервер hbbs/hbbr или официальный релей-сервер.
- Подключение всегда видимo владельцу ПК и требует подтверждения.
- Исходный код: https://github.com/rustdesk/rustdesk
