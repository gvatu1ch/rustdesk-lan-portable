# RustDesk LAN — удалённый рабочий стол (аналог AnyDesk)

Портативная сборка [RustDesk](https://github.com/rustdesk/rustdesk) 1.5.0 для Windows x64 для подключения по локальной сети (LAN).

RustDesk — open-source программа под лицензией **AGPL-3.0**. В папке `LICENSE.rustdesk.txt` — текст лицензии.

## Скачивание

Перейди в раздел **Releases** этого репозитория и скачай
`rustdesk-1.5.0-windows-x86_64-portable.zip`. Распакуй в любую папку —
установка не требуется.

## Как пользоваться

### A) Через ID (в разных сетях — через официальный публичный сервер)

### На компьютере, К КОТОРОМУ подключаются

1. Запусти `rustdesk.exe`.
2. Настройки → Сеть → **Прямой доступ по IP** — включи (порт 21118).
3. Оставь подтверждение «вручную»: каждое подключение показывается окном,
   которое нужно принять.

### A) Через ID (в разных сетях — через официальный публичный сервер)

1. Запусти `rustdesk.exe` на **обоих** компьютерах.
2. Убедись, что статус сверху зелёный (**«Готово»**) — иначе перезапусти программу.
3. На компьютере, С КОТОРОГО подключаются, введи **ID (9 цифр)** другого
   компьютера (он показан в главном окне RustDesk) и нажми Enter.
4. На втором ПК появится окно запроса — владелец нажимает **«Принять»**.

### B) По локальной сети (LAN, без сервера)

## Решение проблем

- **«Не подключено, проверьте соединение»** — просто перезапусти `rustdesk.exe`
  (закрой все процессы и снова запусти). Статус сверху должен стать зелёным: **«Готово»**.
- **Ошибка «Failed to find» / долго висит** — обе стороне нужен одинаковый сервер ID.
  По умолчанию обе программы уже используют публичный сервер RustDesk.
- **Версия должна совпадать** — у обоих должна быть сборка **1.5.0**
  из релиза выше. Скачай именно zip из раздела Releases, не из других источников.

## Важно

- Подключение возможно в одной сети (LAN) или через интернет (публичный сервер
  RustDesk либо свой сервер hbbs/hbbr).
- Подключение всегда видимo владельцу ПК и требует подтверждения.
- Исходный код: https://github.com/rustdesk/rustdesk
